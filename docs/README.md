# Learning Catalyst Documentation

Welcome to the documentation for the Learning Catalyst desktop application. The goal of this directory is to keep the most helpful information easy to find and quick to read. Each section below links to short, task-focused guides.

## Directory Overview

| Folder | What you will find |
| --- | --- |
| [`getting-started/`](getting-started/) | Environment prerequisites, installation steps, and a five minute quick start. |
| [`user-guide/`](user-guide/) | Day-to-day usage notes covering the chat workspace, configuration, and troubleshooting tips. |
| [`architecture/`](architecture/) | Concise references for the platform structure, data flow, and operational safeguards. |
| [`plan/`](plan/) | Archived project plans and milestone summaries for major feature initiatives. |

## Writing Principles

- Keep documents focused on the task the reader is trying to accomplish.
- Prefer short sections, tables, and bullet lists over long prose.
- Update or remove stale content when workflows change.
