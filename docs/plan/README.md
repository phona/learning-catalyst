# Planning Archive

This directory preserves the implementation plans and retrospective notes for major Learning Catalyst initiatives. The documents are grouped by program so you can quickly locate the relevant research, task breakdowns, and completion summaries.

## Directory Overview

| Folder | Description |
| --- | --- |
| [`context-aware-practice/`](context-aware-practice/) | The multi-phase practice curriculum, including detailed implementation plans, weekly reports, and completion summaries. |
| [`langchain/`](langchain/) | LangChain migration blueprints, technical deep dives, and milestone reports covering the transition to the current desktop experience. |
| [`test-hardening-plan.md`](test-hardening-plan.md) | Strategy outline for stabilizing automated testing and CI signal. |

### LangChain Documentation Layout

The LangChain archive is organized into two sections:

- [`docs/`](langchain/docs/) – Architecture briefs, migration checklists, and technical guides produced during the planning phase.
- [`implement-summary/`](langchain/implement-summary/) – Phase-by-phase completion summaries recorded after each milestone.

### Context-Aware Practice Layout

- [`docs/`](context-aware-practice/docs/) – Source plans and to-do lists for each stage of the practice initiative.
- [`implement-summary/`](context-aware-practice/implement-summary/) – Post-implementation summaries and weekly progress reports.

These materials are read-only references; keep them intact to preserve historical knowledge for future projects.
