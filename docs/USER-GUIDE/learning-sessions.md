# Learning Sessions Guide

Learning Sessions help you **structure your study time**, track progress, and maintain continuity in your learning journey.

## What Are Learning Sessions?

**Organized periods of focused learning**

Think of sessions like **chapters in a book**:
- Each session has a **specific focus** (e.g., "React Hooks")
- You can **start, pause, and resume** anytime
- Progress is **saved automatically**
- Full **history preserved**
- Create **checkpoints** for important moments

## Creating a Session

### Method 1: From Dashboard

```
1. Dashboard → "New Session" button
2. Choose template or "Custom"
3. Enter session details:
   • Title: "Python Data Structures"
   • Description: "Learn lists, dicts, sets, tuples"
   • Duration: 60 minutes (target)
   • Difficulty: Intermediate
   • Goals: What you want to achieve
4. Click "Start Session"
```

### Method 2: From Chat

```
1. Chat → "Start New Chat"
2. Begin asking questions
3. Session auto-creates with your topic
4. Rename if needed: Chat header → Edit name
```

### Method 3: Import Materials

```
1. Settings → Materials → Import Files
2. Select your files (PDF, MD, code)
3. Auto-creates session based on content
4. Review and adjust
5. Start learning!
```

## Session Management

### Starting a Session

```

2. Click "Continue" button

From Sidebar:
1. Click session name
2. Opens chat with session context
```

### Pausing a Session

```
How to pause:
1. Chat header → "Pause Session" button
2. State saved automatically
3. Can resume anytime

When to pause:
• Taking a break
• Need to research something
```

### Ending a Session

## Checkpoints

### What Are Checkpoints?

**Snapshots of important moments**

Think of checkpoints like **save points in a game**:
- Capture current state
- Can restore anytime
- Preserve context
- Useful for milestones

### Creating Checkpoints

```
Manual checkpoint:
1. Chat → "Save Checkpoint" button
2. Add name: "Finally understand closures!"
3. Add note: "Had that 'aha!' moment"
4. Save

Automatic checkpoints:
• Every 30 minutes
• After mastering a concept
• Before difficult topics
• End of session
```

### Using Checkpoints

```
Restore checkpoint:
1. Dashboard → "Checkpoints" tab
2. Find checkpoint
3. Click "Restore"
4. Return to that moment

Share checkpoint:
1. Right-click checkpoint
2. "Share Link"
3. Copy link
4. Send to friends/teachers
```

### Checkpoint Examples

```
Great checkpoint moments:
✓ "Learned React useState"
✓ "Completed first algorithm"
✓ "Built my first component"
✓ "Understood recursion"
✓ "Fixed this tricky bug"
✓ "Just finished chapter 1"
✓ "Passed practice quiz"
✓ "Made breakthrough on project"
```

## Best Practices

### 1. Consistent Sessions

```
Establish routine:
• Same time daily
• Regular breaks
• Focused environment
• Clear goals
• Session notes

Example schedule:
Monday/Wednesday/Friday: 60 min sessions
Tuesday/Thursday: Practice (30 min)
Weekend: Review (45 min)
```

### 2. Break Down Large Topics

```
Instead of:
"Learn Python" (too broad)

Do:
Week 1: Python Basics (variables, data types)
Week 2: Control Flow (if, loops, functions)
Week 3: Data Structures (lists, dicts, sets)
Week 4: OOP (classes, objects, inheritance)
```

## Troubleshooting

### Session Not Saving

**Symptoms**: Progress lost, can't resume

**Solutions**:
```
1. Check internet connection
2. Verify database write permissions
3. Restart application
4. Check disk space
5. Export data as backup
```

### Can't Find Past Session

**Symptoms**: Session disappeared

**Solutions**:
```
1. Dashboard → "All Sessions" tab
2. Search by date/topic
3. Check archived sessions
4. Verify filters
5. Restore from backup
```

### Progress Stuck

**Symptoms**: Progress bar not moving

**Solutions**:
```
1. Refresh dashboard
2. Complete an activity
3. Ask AI to update progress
4. Check session is active
5. Restart session
```

### Checkpoint Not Working

**Symptoms**: Can't save or restore

**Solutions**:
```
1. Check checkpoint limit (100 max)
2. Verify session exists
3. Try manual checkpoint
4. Export session data
5. Contact support
```

## Tips & Tricks

### 1. Session Naming

```
Good names:
✓ "React Hooks - useState & useEffect"
✓ "Python Data Structures Practice"
✓ "JavaScript Closures Deep Dive"
✓ "Interview Prep - Algorithms"

Avoid:
❌ "Session 1"
❌ "Study"
❌ "Learning"
❌ "Untitled"
```

### 2. Session Descriptions

```
Include:
• What you'll learn
• Prerequisites
• Goals
• Expected duration
• Materials needed

Example:
"Learn React hooks by building a todo app.
Prerequisites: Basic React knowledge.
Goals: Master useState, useEffect.
Duration: 60 minutes.
Materials: Code editor."
```

### 3. Managing Multiple Sessions

```
Keep organized:
• Use clear titles
• Set realistic timeframes
• Prioritize active sessions
• Archive completed ones
• Regular cleanup
```

### 4. Tracking Retention

```
Test yourself:
• Review checkpoint notes
• Try explaining concepts
• Build something with new knowledge
• Teach someone else
• Quiz yourself
```

### 5. Session Intensity

```
Find your sweet spot:
• Short sessions (15-30 min): Quick learning
• Medium sessions (30-60 min): Balanced
• Long sessions (60+ min): Deep focus

Adjust based on:
• Topic difficulty
• Available time
• Energy level
• Learning goals
```
